# greet — Specification

#### FR-GREET-01: Greet a person by name
`greet(name)` returns a greeting with the person's name. *Why:* people like to be called by their name.

#### FR-GREET-03: Greet with a chosen salutation
`greetWith(salutation, name)` greets the person with the salutation given. *Why:* "Hello" does not suit every moment.
